# Evidence-first app builder: logo brief

## 0. Routing

- Mode: one_shot. Kit tier: medium. Grill: skipped, settings supplied.
- Category: oss_repo_mark. Preview artifacts: concept sheet, tiles and HTML.
- Platform pack: favicon, iOS and Android. Social: all SVG and PNG cards.
- Gallery publish: skipped. QA images stay with the kit.
- Banner column 3: product-card, a feature gate review rather than a VCS diff.
- Approved source: none, drafting fresh.
- Context sources: README.md, skills/evidence-first-app-builder/SKILL.md,
  references/outputs.md and the owner's brand instructions.
- Unknown after lookup: legal entity, existing theme and prior approved identity
  were not found. No legal or contact lines are invented.
- Intent: Give builders and coding agents a recognisable evidence-first gate.
  A dense, angular document frame becomes a threshold check, with a quiet
  two-line wordmark and an explicit study-to-code sequence. The medium kit must
  remain useful at favicon size, without stock glyphs or decorative AI imagery.

## 0b. Strategy and metaphor

- Category/audience: app-building workflow skill for developers and coding agents.
- Function: make feature implementation wait for accepted docs and design.
- Promise/trust: deliberate progress, claims supported by proof.
- Position: builder-native and editorial, not a code-generation magic trick.
- Visual world: document margins, review frames and measured thresholds.
- Core metaphor: a document frame opens into the check-shaped gate to building.
- Mode: dark developer, flat surfaces with an ink-and-paper character.
- Method: threshold uses metaphor fusion and construction geometry.
  Fold uses product action. Bracket uses negative space and metaphor fusion.
- Public brand: evidence-first-app-builder. Display: evidence-first / app builder.
- Legal name: unknown, looked and not found.
- Lockup: one_shot choice, bold primary line and smaller tracked descriptor.
- Board rhythm: quiet symbol, functional banner, technical size ladder,
  detailed comparison. No stock scenes or decorative UI fragments.

## 1. Copy and colour

- Primary wordmark: evidence-first, 30px. Descriptor: app builder, 20px.
- Cursor: omitted, the threshold is the action, not a simulated terminal.
- Tagline: Docs and design before code. Adapted from README.md introduction.
- Motto: Proof at every step. Derived from the documented checklist method.
- Pills: Docs, width 61; Design, width 76. Formula: ceil(chars * 7.2) + 32.
  Total width 145, below the 248px column limit.
- Column 2 starts at 184, card at 456. All copy ends before 432.
- Palette source: assets/brand/tokens.json. Assumed because no theme existed,
  as explicitly permitted for this one_shot request.
- bg #161b20: canvas and surfaces. fg #f3eee4: primary text and document.
- muted #a8b0b5: labels and borders. accent #ed9864: threshold and acceptance.
- Other roles alias these four tokens. No red/green diff semantics apply.
- Generic exporter colours are remapped to these tokens before final rendering.
  Mono/reversed variants use foreground/background tokens, not pure black/white.

## 2. Column 3 story

- Header: FEATURE / F01, GATE REVIEW.
- Rows: Scope and test recipe; Frames and runtime handoff;
  Accepted. Ready to build.
- Pipeline: study, design, gate, code. This is a method illustration, not a
  claim that any real app feature has passed its checks.

## 3. Research and concepts

Study-only references: library/svg/linear.svg and library/svg/figma.svg from the
skill library. Linear demonstrates strong reduction. Figma demonstrates reusable
construction units. Neither geometry nor artwork is reused.

Ten ideas: threshold document, folded approval, bracket gate, proof tab,
open margin, aligned pages, measured doorway, cut E, stepped lintel, ruled stamp.
Survivors: Threshold, Fold and Bracket, supplied as single-colour concept SVGs.
Threshold wins because the check is structural, not a badge pasted onto a page.
Fold is too literal. Bracket is too close to generic developer-tool shorthand.

Cliches rejected: floating tick badges, sparkles, bolts, stock outline documents,
neon gradients. No icon-set artwork is included.

## 4. Adversarial review and limits

- Keep the gate stroke heavy enough to survive 16px. No thin internal rules.
- Preserve identical mark paths in icon, banner and social placements.
- Separate mark, wordmark and review card with fixed gutters.
- Avoid a long repo slug in social title rows. Use the display wordmark.
- Static SVG elements remain visible without CSS animation support.
- Motion draws the threshold, holds the completed state, then resets.
  Reduced motion forces the final still. No scripts or external fonts.
- Kit exporters provide the output scaffolding. Their stock palette is replaced.
- GitHub social preview upload is an owner action, not performed by this commit.
- Render review found the exporter omitted linked SVG images in social PNGs.
  Social SVGs now inline the mark. Its fill-only mono exporter also left coloured
  strokes, so both mono variants now use a single ink colour on contrasting paper.
- Inspected icon, banner, concept sheet, size ladder, 16px favicon, mono variants
  and corrected GitHub/square cards. No clipping or text collisions remained.
  CSS timing and reduced-motion rules are audited, not browser-playback tested.
